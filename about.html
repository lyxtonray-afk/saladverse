About This Project

Salad Recipe Catalog is a Web Technologies mini project created by a 1st-year B.Tech student to explore and catalog healthy salad recipes. The main objective of this website is to demonstrate core frontend development concepts using HTML5, CSS3, JavaScript DOM manipulation, and Bootstrap 5 without any backend or external frameworks.

Key Technologies & Features

  • HTML5: Semantic page structure (<nav>, <main>, <section>, <footer>).
  • CSS3 & Bootstrap 5: Responsive grid layout, light gray cards, and custom dark green styling.
  • JavaScript DOM Manipulation: Dynamically generating 15 recipe cards from an array of objects.
  • Search & Filter: Case-insensitive real-time search by recipe name and category filtering.
  • Browser Local Storage: Saving and removing user favorites across page reloads.
